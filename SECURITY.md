# Política de segurança

## Versões com suporte

O projeto está em fase de protótipo. Apenas o código do branch `main` recebe correções.

## Como relatar uma vulnerabilidade

Não abra uma issue pública para falhas de segurança. Entre em contato diretamente com os responsáveis pelo projeto, descrevendo o problema e como reproduzi-lo.

Responderemos assim que possível. Como este é um projeto de estudantes, sem equipe dedicada, não há prazo garantido.

## Dados pessoais

O protótipo não envia dados para nenhum servidor: tudo fica na memória do navegador e se perde ao recarregar a página. As informações de acessibilidade escolhidas no cadastro nunca saem do aparelho. Se o projeto passar a ter backend, esta política será revista antes.
