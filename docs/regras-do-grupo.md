# Regras do grupo

Estas regras vieram do documento escrito pelo grupo quando o grupo de estudos nasceu. Elas estão dentro do app, na tela "Regras", e valem também para este repositório.

## 1. Respeito e tolerância zero a ofensas
Nenhuma ofensa é aceita, em nenhuma forma: nem brincadeira, nem indireta.

## 2. Respeito às diferenças
O grupo reúne pessoas de origens, idades, crenças e níveis de estudo diferentes. Essa diferença é o que faz a troca valer.

## 3. Um ambiente para aprender
Todo mundo está aqui para aprender, inclusive quem ensina. Errar faz parte do processo.

## 4. Correções respeitosas
Corrigir é ajudar: aponte o erro, explique o porquê e siga em frente. Ninguém é corrigido com deboche.

## 5. Português para dúvidas
Não saber dizer algo em inglês nunca é motivo de vergonha. O português está sempre liberado para tirar dúvidas.

## Inclusão

Todos podem praticar, aprender, ajudar e ser ajudados. O app foi desenhado para que a presença de uma pessoa com deficiência não seja exceção, e sim parte do funcionamento normal do grupo.
